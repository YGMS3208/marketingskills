# Obsidian導入つまずき note ＋ Threads投稿セット

| ファイル | 内容 |
|---|---|
| `article.md` | note記事の原稿（無料記事） |
| `note_paste.txt` | noteの本文欄にそのまま貼る用 |
| `title.txt` | タイトル |
| `cover.png` | 見出し画像（1280×670） |
| `threads-posts.md` | Threads投稿5パターン（スレッド型・共感型・ビフォーアフター型・問いかけ型・note告知） |
| `meta.json` / `report.json` | ハッシュタグ・前提・文字数レポート |

公開前に `article.md` の【】部分を自分の体験に差し替えてください。

## スマホで公開する手順
1. noteアプリではなく、Safari／Chromeで note.com を開いてログイン
2. 投稿 → テキスト
3. 見出し画像に `cover.png` を設定
4. `title.txt` をタイトル欄、`note_paste.txt` を本文欄に貼る
5. 見出し・太字・リストの反映を確認し、【】部分を書き換える
6. 公開に進む → ハッシュタグを入れて投稿
